# Garde — Smart Wardrobe

Garde is a smart wardrobe assistant that helps users manage their clothes, plan outfits, and make more conscious fashion decisions.

It combines computer vision, AI assistance, and a mobile-first interface to bridge the gap between digital wardrobe apps and real-life clothing.

---

## What it does

Garde turns your wardrobe into an interactive system:

- Add clothes using a photo  
  Upload or take a picture and the app detects multiple garments automatically.

- Build a digital wardrobe  
  Store, edit, and organize clothing items by category.

- Generate outfit suggestions  
  Get recommendations based on your wardrobe and the current weather.

- Use an AI stylist assistant  
  Ask questions such as:
  - "What can I wear with this?"
  - "Should I buy this item?"

  The assistant uses your wardrobe context to provide meaningful answers and promotes reuse over unnecessary purchases.

- Support sustainable decisions  
  Encourages better use of existing clothing instead of overconsumption.

---

## How it works

Garde integrates multiple components into a single flow:

- Computer vision  
  Detects clothing items from images and extracts attributes.

- AI assistant  
  Generates contextual responses based on wardrobe data and user input.

- Weather integration  
  Adapts outfit suggestions to real-world conditions.

- Frontend application  
  A mobile-first interface designed for fast and intuitive interaction.

---

## Tech stack

- Frontend: HTML, CSS, Vanilla JavaScript  
- Backend logic: Serverless functions (Vercel)  
- AI: LLM-based assistant  
- Vision: Image detection and background removal APIs  
- Deployment: Vercel

## Project context

This project was developed as part of a course on product prototyping with data and AI.

The focus was not only on building functionality, but on designing a system that integrates:

- AI capabilities  
- Real-world context  
- User-centered interaction  

---

## Key learnings

- The biggest challenges were not technical, but related to usability and clarity  
- Early assumptions about user behavior were often incorrect  
- Testing with real users significantly improved the product  
- Using external APIs allowed faster iteration and better focus on user experience  
- AI becomes valuable when it is grounded in context, not just generating responses
